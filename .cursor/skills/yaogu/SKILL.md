# 妖股执行

这本账和主仓分开。行为分、四条路径、板块看涨不进分类，也不改 9:15 已锁定的主仓卖出。模块是 `python -m astock.yaogu`。模块只分类、只排盘前五只，不下单，不改权重。

金螳螂只卖，中信金属现价低于 9.55 减 1000，万向钱潮和中国能建不加。这四只代码在模块的 `BLOCKED` 里，进不了隔夜。

## 窗口

可排队从 **2026-12-01** 到 **2027-02-06** 之前。2027-02-06 是春节当天，最后交易日以交易所休市公告为准，公告日前的交易日仍可排队。2026-12-01 之前照样分类、照样出盘前五只，输出写「窗口未开，不排队」。

## 进池

同时满足：代码前三位是 600、601、603、605、000、001、002、003；名称没有 ST、没有退市；这一轮首板收盘价低于 10 元；首板发生在窗口内。新股可以进池，不加分。第 1 板的首板价用当日收盘。第 2 板及以上必须带上首板收盘价，缺了就标池外。

## 每天

时间是北京时间。非交易日只写「非交易日」。

| 时点 | 动作 |
| --- | --- |
| 9:00 | 盘前。用昨夜分类。先跑 `--day` 和 `--rows`，把印出的五只写进答复。已成交的隔夜、仍持有的一字，9:15–9:25 卖出。没成交的不追。用户没报成交股数时只写价位，不编股数 |
| 9:25 | 记下盘前五只里隔夜档的开盘价，以及持仓档的开盘价 |
| 10:00、12:50、14:00 | 盘中。账应当是空的，还有仓就卖。只看正在冲第 2 板或第 3 板、首板价低于 10 元的监控票。每只标一个：一字封死、换手封板中、已经开板、成交量已到昨日 2.2 倍。一字和 2.2 倍离开尾盘队列。14:00 的候选不是单 |
| 14:55 | 仍是第 2 或第 3 板、换手、量比仍低于 1.3，才按收盘价排队。量比到 2.2 就撤。窗口未开则不排 |
| 15:10 | 收盘。用全天开高低收和成交量重跑分类，核对 14:55 的单。结算昨天：一字是否还涨停，被否决的开盘中位数，隔夜开盘胜率和中位数 |

盘前五只的顺序由 `top5` 固定：隔夜档在前，量比低的在前；然后是第 2、第 3 板一字；再是第 1 板一字。观察档不补进这五席。不足 5 只就写实际只数。

## 收盘四档

量比是当日成交量除以上一交易日成交量。一字：最高减最低不超过 1 分钱，或不超过收盘价的 0.15%。开盘在涨停价、盘中有回落再封死，是 T 字。其余封死是换手。

- **持仓。** 一字，且板数是 1、2 或 3。预测次日还涨停。不新买。
- **否决。** 第 2 板换手，量比达到 2.2。出池。
- **隔夜。** 第 2 或第 3 板换手，量比低于 1.3。预测次日开盘高于今日收盘。排到的次日集合竞价卖出，只持有一夜。
- **观察。** 其余进池的票。包括第 1 板换手、T 字、第 2 板量比在 1.3 到 2.2 之间、第 4 板及以后。

锚：第 2 板一字次日还板 60%；否决档开盘中位数 0；隔夜开盘中位数 +5.0%，胜率 81%。

## 停机和影子

隔夜最近 15 笔胜率落到 50% 或以下，或中位数落到 0 或以下，下一笔起停止新开，影子继续记。连续 10 笔影子重新达到胜率 70% 以上、中位数高于 0，才恢复排队。一字结算满 20 笔、次日还板率低于 40%，这档只留记录。

量比上界整个窗口最多收紧一次，只从 1.3 收到 1.0。条件是隔夜已结算至少 40 笔，低于 1.0 和 1.0 到 1.3 两组都至少 15 笔，且低于 1.0 那组的开盘中位数高出至少 2 个百分点、胜率也更高。否决线 2.2 在窗口途中不动。

影子每天记、本窗口不买：第 2 板换手且量比在 1.3 到 2.2、第 2 板换手且量比达到 2.8、第 1 板换手且量比低于 1.3。同板块家数和流通市值不进活规则。

## 初始监控

23 只，种子日 2026-11-09。名单以 `python -m astock.yaogu --monitor` 为准。断板的留到次日开盘记完，再移出当日队列。这份种子保留到 2026-12-01，用来对照第一笔结算。12 月 1 日之后，新票只从当日进池规则进来。

## 输入

`--rows` 是 JSON 列表。每只要有 `code`、`name`、`board`、`open`、`high`、`low`、`close`、`prev_close`、`volume`、`prev_volume`。第 2 板及以上再给 `first_close`。

```
python -m astock.yaogu --monitor
python -m astock.yaogu --day 2026-11-10 --rows rows.json
```
