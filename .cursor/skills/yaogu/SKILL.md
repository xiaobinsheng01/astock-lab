# 妖股执行

这本账和主仓分开。行为分、四条路径、板块看涨不进分类，也不改 9:15 已锁定的主仓卖出。模块是 `python -m astock.yaogu`。模块只分类、只排盘前五只，不下单，不改权重。

金螳螂只卖，中信金属现价低于 9.55 减 1000，万向钱潮和中国能建不加。这四只代码在模块的 `BLOCKED` 里，进不了隔夜。

## 窗口

可排队从 **2026-12-01** 到 **2027-02-06** 之前。2027-02-06 是春节当天，最后交易日以交易所休市公告为准，公告日前的交易日仍可排队。2026-12-01 之前照样分类、照样出盘前五只，输出写「窗口未开，不排队」。

## 进池

同时满足：代码前三位是 600、601、603、605、000、001、002、003；名称没有 ST、没有退市；这一轮首板收盘价低于 10 元；首板发生在窗口内。新股可以进池，不加分。第 1 板的首板价用当日收盘。第 2 板及以上必须带上首板收盘价，缺了就标池外。

## 每天

时间是北京时间。非交易日只写「非交易日」。

| 时点 | 动作 |
| --- | --- |
| 9:00 | 盘前核对。先跑 `--day` 和 `--rows`。印出的五只只核对，不买。元素六格和情绪、市场写在五只后面。已成交的隔夜在 9:15–9:25 无条件卖出，高开也卖。仍持有的一字同样卖。没成交的不追。用户没报成交股数时只写价位，不编股数 |
| 9:25 | 记下隔夜档的开盘价是否高于昨夜收盘，以及持仓档的开盘价。元素不改这笔卖出 |
| 10:00、12:50、14:00 | 盘中。账应当是空的，还有仓就卖。只看当天正在冲第 2 板或第 3 板、首板价低于 10 元的票。每只标一个：一字封死、换手封板中、T 字回落、已经开板、成交量已到昨日 2.2 倍。旁边写元素和降档。一字和 2.2 倍离开尾盘队列。回落里买到的货，次日开盘同样交出。14:00 的候选不是单 |
| 14:55 | 仍是第 2 或第 3 板、换手，才考虑排队。量用 14:55 以前的成交量，加上昨日最后五分钟的成交量，除以昨日全天成交量。加完仍低于 1.3 才按收盘价排。昨日尾盘量缺失就不排。窗口未开则不排。缩量 T 字不排。降档不撤已经符合量比的单，也不把没过量比的票排进去 |
| 15:10 | 收盘。用全天开高低收和成交量重跑分类，并重写元素。全天量比只记和 14:55 缓冲量比的偏差，不撤销已经成交的单。结算昨天：一字是否还涨停，被否决的开盘中位数，隔夜开盘胜率和中位数 |

盘前五只由 `top5` 固定，标题是核对：隔夜档在前，量比低的在前；然后是第 2、第 3 板一字；再是第 1 板一字。观察和只看不补进这五席。不足 5 只就写实际只数。

## 收盘四档

量比是当日成交量除以上一交易日成交量。一字：最高减最低不超过 1 分钱，或不超过收盘价的 0.15%。开盘在涨停价、盘中有回落再封死，是 T 字。其余封死是换手。

- **持仓。** 一字，且板数是 1、2 或 3。预测次日还涨停。不新买。
- **否决。** 第 2 板换手，量比达到 2.2。出池。
- **隔夜。** 第 2 或第 3 板换手，量比低于 1.3。预测次日开盘高于今日收盘。排到的次日集合竞价卖出，只持有一夜。
- **只看。** 第 2 或第 3 板的 T 字，且量比低于 1.3。不排队。盘中回落里若买到，卖法与隔夜相同，仓位记在影子，不并进隔夜额度。影子开盘中位数落到 0 或以下，这档连看都不留。放量 T 字仍是观察。
- **观察。** 其余进池的票。包括第 1 板换手、放量 T 字、第 2 板量比在 1.3 到 2.2 之间、第 4 板及以后。

锚：第 2 板一字次日还板 60%；否决档开盘中位数 0；隔夜开盘中位数 +5.0%，胜率 81%。

## 元素

六格和情绪、市场写在每个时点的档位旁边。不改持仓、否决、隔夜、只看、观察。不改盘前五只的顺序。不进 14:55 的排队条件。谐音、股吧故事、没有发布时间的标题只留影子，不进这六格。

| 格 | 收什么 | 怎样才写上 |
| --- | --- | --- |
| 文件 | 规划、通知、文号 | 有发布时间，并且点到代码、行业或名称里的词。用 `--official` |
| 会议 | 政治局、中央经济工作会议、部委发布 | 通稿已经出来，同样要有发布时间 |
| 数字 | 规划里的产量、金额 | 是新的官方数字。和已经记过的纲要重复，不写 |
| 名称簇 | 去掉公司通字后，同一天至少两只共享的两个字 | 行业可以不同。东方按这个格子数，不单开一档 |
| 生肖 | 窗口对着的羊 | 涨停名称里有「羊」，或带发布时间的稿点了「羊」而池中无票 |
| 地域 | 地名 | 同一天至少两只，行业不相同。上一日也满足，才写成簇；只当天有，写当日 |

情绪用炸板率，市场用该票行业指数的涨跌，都从 `--mood` 读。已经炸板并且炸板率达到 25%，或行业指数下跌，这只写降档。降档只标在分析旁边。同板块家数和流通市值仍不进活规则。

10 月 21 日到 11 月 10 日的涨停池里，东方在 11 月 6 日、9 日凑成跨行业名称簇；羊只有 10 月 26 日三羊马一只；上海、青岛在东方扩开之前就有过同一天地名两只以上。这三段只说明格子怎么数，不改档。

## 停机和影子

隔夜最近 15 笔胜率落到 50% 或以下，或中位数落到 0 或以下，下一笔起停止新开，影子继续记。连续 10 笔影子重新达到胜率 70% 以上、中位数高于 0，才恢复排队。一字结算满 20 笔、次日还板率低于 40%，这档只留记录。

量比上界整个窗口最多收紧一次，只从 1.3 收到 1.0。条件是隔夜已结算至少 40 笔，低于 1.0 和 1.0 到 1.3 两组都至少 15 笔，且低于 1.0 那组的开盘中位数高出至少 2 个百分点、胜率也更高。否决线 2.2 在窗口途中不动。

影子每天记、本窗口不买：第 2 板换手且量比在 1.3 到 2.2、第 2 板换手且量比达到 2.8、第 1 板换手且量比低于 1.3。同板块家数和流通市值不进活规则。

## 结算样本

23 只，种子日 2026-11-09。名单以 `python -m astock.yaogu --monitor` 为准，标题写明不是每日监控池。只用来结清这一笔对照：隔夜记开盘，一字记还板与否，记完移出当日队列。10:00 的监控只看当天正在冲第 2 板或第 3 板的票。

## 输入

`--rows` 是 JSON 列表。每只要有 `code`、`name`、`board`、`open`、`high`、`low`、`close`、`prev_close`、`volume`、`prev_volume`。第 2 板及以上再给 `first_close`。有行业再给 `hy`。已经炸板给 `broken`。14:55 的排队另给 `volume_1455` 和 `last5_volume`（昨日最后五分钟成交量）。缺 `last5_volume` 就不排。`--prior` 是上一日涨停名单。`--official` 是文件、会议、数字。`--mood` 给 `broken_ratio` 和 `sector_pct`。

```
python -m astock.yaogu --monitor
python -m astock.yaogu --day 2026-11-10 --rows rows.json
```
