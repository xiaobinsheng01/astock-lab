# 第 5 层 · 执行

终分之后才改单。盘中只核对卖出区。节名与拆分前相同。

## 三种模式

### A. 次日 9:00 终分（才允许按新分执行 9:15 单）

1. 扫执行流程里「次日 9:00 全扫」+ 官方渠道表（央行、联播、新华社 news.cn、发改委 ndrc.gov.cn、央视财经频道 tv.cctv.com、中国财富网 cfbond.com、中证网、三报、其余部委、交易所融资、巨潮、美股现金、CME、商品、富时中国 A50 夜盘）。资料面按「资料面增量」，只打开状态为待确认、待9:00、未挂的页。记录里已确认的地址不再打开。新华社、发改委、央视财经频道、中国财富网按「取数」节核对时间戳；与已入账事实重复的不另加分。A50 按「外围」节写高开、平开或低开。外围市场资讯引用记录里已经入账的选举结果，已有地址不再打开。
2. 终分 **替换** 昨晚初分；写明「初分 → 终分」哪些项变了。
3. 完整顺序：资料 → W8/W7 → 行为分 → 板块看涨 → **大盘四态** → 五行结论。上证日线四格没齐，W7 不打分，也不记 0。缺口不把已经达到 0.4 的分数改回震荡。卖出股数仍按硬门。
4. 指数硬区间、窄区间、A50 方向、对冲、托住和国家队措辞按「预测」节写。窄区间用上一份收盘对照改过的上下沿，不沿用已经未命中的窄区间。
5. 终分完成后，才确认 9:15 卖出价位和股数。股数用当晚初分里用户已提供的持仓。初分仍是「待提供」时，终分只写价位，不编股数。盘中现价用 `close_inputs.py --fast`。
6. 昨夜「今日关注」按该节复核。时间窗仍是上一个交易日 00:00 到当前时刻。挂出时间落到窗外的从终分删去。交易所列表昨夜已有、PDF 今早才打开的，用原文改数字，不新加一只。今早不从股吧或热榜补名字。
7. 五行之后按「发力板块」和「发力个股」写两列。脚本是 `scripts/sector_drive.py`。六项门槛全部计算。答复按 `names` 里的全部过线名字写，不用 `priority` 的前十只代替名单。这两列不进 W1–W8，不改行为分，不改主路径，不改修复日，不改 9:15。行为分低于 0.4 时只标记，不开仓，不加仓。

### B. 15:10 起初分 + 19:35 / 17:10 补扫

1. **15:10**：指数、成交、涨跌家数、涨停池、持仓现价；上证 50、沪深 300、中证 1000（缺任一条则指数句停机）。对冲、托住和底仓股价还要中证银行、CSSW 电子；电子缺失时只把对冲写成未核。
2. **16:30**：龙虎榜原文（持仓是否上榜）。
3. **17:10**：央行官网公开市场（打不开标未复核，转载不算已核对）。
4. **19:35**：资料面按「资料面增量」用记录。只打开上一轮游标之后新挂出的稿，记录里已有地址的不再打开。渠道仍是联播文字目录、新华社 news.cn 带时间戳的通稿和受权播发、发改委 ndrc.gov.cn 新闻发布会与通知、央视财经频道已挂出的第一时间、正点财经、交易时间、天下财经、中国财富网要闻列表里来源写成中国财富网的稿、中证网头版。**21:20** 那一窗同样只收新稿：经济信息联播和 15:00 后才挂出的正点财经，19:35 还没有的补进初分附录。中国财富网 19:35 之后才挂出的，留到次日 9:00，不单开附录。15:00 前和 15:00 到 19:35 已在记录里的稿，初分引用记录入账，不再打开。次日 9:00 只确认待确认、待9:00、未挂，不改已收盘的买卖。
5. **19:40**：上期所日盘结算、巨潮和交易所公告列表。公司公告按「今日关注」筛，挂出时间只取上一个交易日 00:00 到当前时刻，最多十只。候选超过十只时，按挂出时间从新到旧留十只。
6. 先跑 `python3 .cursor/skills/a-share-analysis/scripts/close_inputs.py`。指数、家数、涨停行业、修复两项、`structure` 里的对冲、托住、`book_price`、卖出区、`w6`、`sector_state` 以脚本输出为准。五维里能打分的不足 4 维，W6 不合成。量能对不上当日行情时不打分。股数锚不由这支脚本更新。催化日期脚本写 false，候选不由脚本升成。
7. 产出初分行为分 + 板块状态 + 大盘四态，并按「预测」节写早盘对照。上证和每只持仓按「缠论」节写日线四格。五行和早盘对照之后写「今日关注」。一只都没打开就写「今日关注：无」。**不**因初分改次日 9:15 已锁定的终分单。初分向用户要股数、可用、成本、上一笔是否成交。还没提供时，价位条件照写，持仓写「待提供」。

### C. 盘中实时（用户随时问，或 9:45 / 11:30 / 13:05）

**允许改的只有四项**（与执行流程一致）：

- W6 原料（家数、涨停/跌停/炸板、溢价、高度、成交）
- 持仓现价与是否进入卖出区
- 30 分钟买卖点。只改卖出节奏，不改日线笔的方向。日线四格没齐，W7 保持缺口，不记 0
- 板块涨停 **只数**（重算板块状态：未核 / 不成立 / 第一天 / 候选）

**禁止：**

- 因盘中板块候选、普涨、银行下跌、托住、修复或 30 分钟买点，把行为分标签从震荡改成可开仓。
- 把日线向下笔改成向上，或把 W7 缺口记成 0。
- 因实时分析取消金螳螂只卖、中信 9.55 减 1000、或万向/机器人开仓（除非用户明确改 H，且仍要行为分 ≥ 0.4、金螳螂 ≤6000、板块候选）。
- 用界面新闻上午北向快照充收盘净买入；北向无净买入字段则写缺口。
- 在盘中重算 W8 报告期，或把还没收盘的美股、美债、原油、沪铜、美元写进 W3。记录里状态已经是「本轮已用」的官方事实，盘中引用那一格，不再等 19:35 或次日 9:00。用户指出央行、新华社、发改委、央视财经频道、中国财富网或联播的突发硬新闻，而两小时增量还没写到时，当轮只更新受影响的权重，标明「盘中例外」，仍不写开仓。中国财富网的转载不构成突发硬新闻。

**盘中优先数据源（快）：**

- 现价：`qt.gtimg.cn`
- 情绪/涨停：选股宝收盘前用 flash/API；东财 push2 502 时换腾讯 + 选股宝
- 不为此模式全扫巨潮、联播、新华社、发改委、央视财经频道、中国财富网。新的官方数字由资料面增量当轮使用。盘中六行引用已经标明「本轮已用」的那一格。这一窗没有新的官方数字，行为分不动。

**盘中产出（短，六行以内）：**

六行正文在 `references/06-output.md`「盘中六行」。

交易日 10:00、12:50、14:00 不走这六行，走「盘中分析」。

### D. 盘中分析（交易日 10:00、12:50、14:00）

这三个钟点各做一轮。顺序固定：先收资料，再写接下来的走势，再写个股表。资料、四条路径、板块句和个股筛选都做完。不改 W3 的符号规则，不改窄区间上沿规则，不改 9.55，不改金螳螂只卖。这一窗没有新的官方数字，就不改行为分。有新的官方数字，只按「当轮使用」改受影响的那一格。行为分不在盘中整表重算，是计分时点留在初分和终分，不是把资料和个股留到那时再看。当日高点越过上一交易日高点后，主路径改到收在昨日高点之上。行为分低于 0.4 时不开仓、不加仓。这一轮不重订定时。

上证当日没有开盘价，只写「非交易日」，停在这里。

1. 资料面跑 `scripts/info_diff.py`，不打开 `info-ledger.md` 全文。脚本已经去掉记录里有的地址，并把本窗和缺口里带时分的新稿全部收成一行，不按条数留下一轮。`empty` 为真就写「这一窗没有新稿」，并把游标推到当前时刻。`undated_count` 只在答复里写个数；点了电子、芯片、通信、银行、食品饮料、煤炭的无时分标题全部写在板块句旁边，不打开。原页只写了涨跌、没有价格或金额时，按「取数」用网页和 X 补同一事实。游标不退回。这一步按「当轮使用」处理。没有新的官方数字，行为分不动。
2. 走势用已经写好的四条路径。点位跑 `scripts/intraday_brief.py`，参数用当日低点、高点。写上证现价、日内高低，以及现价落在哪一段：昨日低点到中点、中点到昨日高点、昨日高点之上、昨日低点之下。然后写从这一钟点到 15:00 收盘，更可能落在四条里的哪一条。核对条件是收盘点位。12:50 这一轮的「接下来」是 13:00 到 15:00。窄区间上沿仍是上一交易日低点与高点的中点，不高于上一交易日高点，突破不写进窄区间。当日高点已经越过上一交易日高点时，从这一钟点到收盘的主路径改成「收在昨日高点之上」。W3 为负、A50 仍缺最新价或前结，不再把主路径留在窄区间。高点只碰到上一交易日高点、没有越过，不改。收盘后来回到中点或中点之下，这一次改档记错，盘中不把主路径改回去。当日高点还没有越过，并且前收也没有站上再前一日高点时，W3 为负且 A50 缺两个价，主路径仍放在窄区间。A50 只有涨跌幅、没有两个价，继续写缺口。今日关注和已经提供的持仓，各按「个股四条路径」写这一只自己的四条。5 日、10 日均线和前十大不另造价。3.88–4.00 和 9.55 写在路径旁边，不跟着路径改。
3. 板块句只用这一条路径里已经写过的分组。页面点名了电子、芯片、通信、银行、食品饮料、煤炭的，把这篇的时间和标题写在板块句旁边。页面没有点名，就沿用早盘那条板块句，并写「这一窗没有新的板块事实」。不新开一对互斥。新能源、传媒、医药、证券不写进互斥。
4. 个股跑 `scripts/intraday_screen.py`。筛选仍是沪深主板和原中小板，代码前三位 600、601、603、605、000、001、002、003。创业板、科创板、北交所、B 股不进。半导体成分先归科创芯片，电子不再计这些代码。现价同时高于 5 日、10 日均线，均线是前复权、含当日。站上两条均线的名字全部判断前十大，不按涨跌幅留下一轮。行情没取到的才写「本轮未核」。答复按脚本的行抄代码、名称、现价、涨跌幅、两条均线。日线和股东页留在脚本里，判断用脚本印出的全部行。
5. 两格用脚本同一行里的「简单或复杂」「有、无或未核」。判断结果只抄脚本「判断结果」下的名字，并写本期、上一期、股东全名、持股比例。两格有一格未核，或两格都过不了，不进判断结果。一只都没有，写「判断结果：无」。判断结果不写成开仓、加仓或今日关注。同一报告期的前十大缓存在 `cache/holders.json`，不进 git；规则版本变了脚本会重取。
6. 行为分仍用最近一份终分或初分。持仓仍按硬门核对卖出区，不新写股数。14:00 这一轮同时写上证落在四条的哪一段，以及银行与电子是相反还是同向。

## 定时唤醒

用户要求后，用 `cursor-subscriptions` 的定时器唤醒本对话。Cron 按 UTC 写。定时只负责到点打开这一轮，醒来后仍按对应模式拉数、算分。终分、初分在非交易日只写「非交易日」，然后仍要续订。资料面增量和盘中分析不续订。定时不在券商挂 9:15 的单。初分向用户要持仓。终分用当晚初分里已提供的数字；初分仍是「待提供」时不编股数。

这组定时暂定到 **2027-02-28（北京时间）** 停止。**2027-02-21** 由周日续期定时写提醒：初分与终分将于 2027-02-28 到期，到期后不再自动跑。2027-02-21 至 2027-02-28 的初分和终分，结论第一行再写一句「定时将于 2027-02-28 到期」。
