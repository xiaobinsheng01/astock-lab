# 第 6 层 · 产出

按模式选一种，不混写。状态块写在前面，见 `rules/03-account.md`「状态块」。

## 收盘五行

步骤在 `rules/05-execution.md` 的终分、初分。顺序沿用那一节：资料 → W8/W7 → 行为分 → 板块看涨 → 大盘四态 → 五行结论。终分才在五行之后写发力板块、观察列和个股动作表。对照表用 `rules/04-judgment.md`「收盘对照」。初分在五行和早盘对照之后写今日关注。动作只有硬门、核对、观察。行为分低于 0.4 时，发力个股和观察列写观察，不开仓，不加仓。输出不叫推荐。

## 盘中六行

只用于盘中实时（用户随时问，或 9:45 / 11:30 / 13:05）。交易日 10:00、12:50、14:00 不走这六行，走 `rules/05-execution.md`「盘中分析」。

**盘中产出（短，六行以内）：**

1. 时点 + 上证/创业板/科创 50 现价与日内高低。
2. W6 相对上一盘是否变（变则写方向，不变写「W6 锁」）。
3. 大盘四态 **仅写当日**：修复日计数（0/1/2/3）、流出端（银行/煤炭/有色/…）、是否满足两项修复条件；不写月末托底/抽血，也不改国家队股数锚。
4. 板块一行：状态是否因只数变化而升级（默认仍不进权重）。
5. 持仓用最近一份终分里的数字。终分仍是「待提供」时，这一行写「待提供」，不新写股数。已提供时，每只写现价 vs 卖出区/9.55，是否现在该动（仍服从 H）。30 分钟卖点可以提前减，股数仍按硬门。30 分钟买点不写进动作。
6. 一句：行为分仍用 **最近终分/初分** 分数，除非硬新闻例外。
